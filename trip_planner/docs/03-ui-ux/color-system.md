## 1. Semantic Color Roles (Light Theme)

| Semantic Role | Hex Value | Contrast vs Background | Purpose / Component |
| :--- | :--- | :---: | :--- |
| `primary` | `#C2410C` (Saffron 700) | **5.4:1** (Passes AA) | Primary CTA buttons, active tab indicators, major headers |
| `onPrimary` | `#FFFFFF` | **5.4:1** | Text and icons placed on primary buttons |
| `secondary` | `#CA8A04` (Marigold 600) | **4.6:1** | Highlights, ritual badges, secondary actions |
| `surface` | `#FFFFFF` | Background base | Standard screen and modal surfaces |
| `surfaceSubtle` | `#F8FAFC` (Stone 50) | Background base | Alternating card backgrounds, unselected chips |
| `textPrimary` | `#0F172A` (Stone 900) | **14.2:1** | High-contrast body copy and headings |
| `textSecondary` | `#475569` (Stone 600) | **6.8:1** | Supporting captions, timestamps, distance labels |
| `borderSubtle` | `#E2E8F0` (Stone 200) | 1.3:1 | Card borders, dividers, chip outlines |

## 2. Specialized Domain Semantic Colors

* **Spiritual / Aarti State (`#F97316`)**: Saffron/Amber glow for live or upcoming aarti slots.
* **Verified / Official Trust Badge (`#15803D`)**: Deep satvik green tag signifying verified temple authority or licensed business.
* **Closed / Attention Warning (`#B91C1C`)**: High-contrast vermilion red alert for closed temple gates, dress code bans, or road diversions.
* **Accessibility Indicator (`#0284C7`)**: Clear sky-blue for wheelchair, ropeway, and senior-citizen accommodations.
