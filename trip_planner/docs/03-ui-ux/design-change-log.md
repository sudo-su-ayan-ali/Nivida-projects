## [v1.0.0] - 2026-10-29 (Initial Baseline Release)

### Added
* Complete atomic design token architecture (`design-tokens.md`) with primitives and semantic roles.
* Saffron, Marigold, Temple Stone, Satvik Green, and Vermilion Red color scales.
* 8-point spacing grid and responsive breakpoint specifications ($<600\text{dp}$, $600–840\text{dp}$, $\ge 840\text{dp}$).
* Typography hierarchy supporting English (`Inter`), Hindi (`Noto Sans Devanagari`), and Gujarati (`Noto Sans Gujarati`).
* Core component specifications: `YatraPrimaryButton`, `YatraVerifiedBadge`, `YatraTimingPill`, `YatraDestinationCard`, and `YatraItinerarySlotTile`.
* Multi-theme architecture supporting Light (sunlight readability) and Dark modes.
* Full WCAG 2.1 AA accessibility specifications (48×48dp targets, 4.5:1 contrast, TalkBack labels).
